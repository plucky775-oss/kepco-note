개발자 : 안산지사 최재혁 차장

노트는 이 기기의 브라우저에 저장합니다. 기본 필기·획 보정·폰트 설정·사진과 PDF 처리는 기기 안에서 이루어집니다.

폰트와 텍스트

상단 ‘폰트’에서 글씨체와 크기를 고르고, ‘텍스트’에서 글을 입력하거나 붙여넣으세요. 텍스트 입력창의 Pencil 손글씨 인식은 iPad 자체 기능이며 앱 AI를 사용하지 않습니다. 기본 폰트는 새로 추가하는 글에 적용됩니다. 기존 글은 올가미로 선택해 ‘선택 폰트 적용’을 누르세요. 폰트 선택만으로 종이에 그린 원본 획이 문자로 바뀌지는 않습니다.

필기 보정과 누르기

‘폰트 → 필기 보정’에서 획 다듬기와 손가락 필기를 설정합니다. 획 다듬기는 작은 흔들림을 완화할 뿐 글자의 뜻·악필의 모양·간격을 교정하지 않습니다. ‘누르고 있으면 도형 보정’을 켜면 한 획으로 그린 직선·큰 원·타원·볼록한 3–8각형을 약 0.6초 멈춰 정돈할 수 있습니다. 작은 글씨·오목하거나 복잡한 모양은 제외되며 모든 모양의 보정을 보장하지 않습니다. 실행 취소로 되돌릴 수 있습니다.

도형과 표

상단 ‘도형’에서 도구를 골라 종이에 끌어 그리세요. 하나를 완성하면 선택·편집 모드가 됩니다. 도형을 선택해 이동하고 모서리 핸들로 크기를 조절하세요. 선은 끝점을 조절합니다. 새 도형을 더 그리려면 도구를 다시 선택하고, 일반 필기로 돌아가려면 ‘펜’을 누르세요. 표도 ‘도형’ 메뉴 안에 있습니다.

다이어리와 알림

상단 ‘다이어리’에서 날짜별 메모·일정·할 일을 관리합니다. 알림은 앱이 열려 있고 화면을 보고 있을 때만 표시됩니다. 앱 종료·화면 잠금 중 정시 알림은 지원하지 않습니다. 캘린더로 내보낸 뒤 기기 캘린더에서 알림 설정을 확인해주세요.

기존 회의 자료 보관

가져온 회의 노트는 일반 노트처럼 열고 PDF 또는 JSON으로 내보낼 수 있습니다. 새 회의와 녹음 생성은 지원하지 않습니다. 이 앱 저장소에 기존 녹음이 있다면 메뉴의 ‘기존 녹음 자료 확인 · 내보내기’에서 원본을 저장하세요.

사진과 PDF

사진은 사진 도구에서 이동·크기 조절·삭제합니다. PDF는 페이지 배경으로 가져와 필기·사진·텍스트를 덧붙이며, PDF 원래 문장을 직접 수정하는 기능은 아닙니다. 가져온 PDF는 노트 백업에 포함되지만 녹음은 별도 다운로드해야 합니다.

안전하게 보관하기

기기 간 동기화는 없습니다. 앱 데이터 삭제나 앱 제거로 노트가 사라질 수 있으니 백업을 저장해주세요. 백업 불러오기는 기존 노트를 덮어쓰지 않고 새 복사본을 추가합니다.

기본 손글씨체는 Google Fonts의 OFL 배포본입니다. 폰트와 PDF 처리에 사용한 외부 구성요소의 저작권·라이선스 원문을 확인할 수 있습니다.

키보드로 글 추가

AI 없이 키보드로 입력하거나 붙여넣은 글을 추가합니다. 이 칸의 Pencil 손글씨 입력은 iPad 자체 인식입니다. 글씨체와 크기는 상단 ‘폰트’에서 선택할 수 있습니다. 기존 글은 그대로 남아요.

추가한 글을 탭하거나 올가미로 선택하면 글·크기 수정, 이동, 삭제가 가능합니다. 취소하면 입력은 저장되지 않습니다.

내보내기 · 보내기

JSON 백업은 원본 획과 두 모드의 내용을 모두 보존합니다.

PNG와 인쇄는 현재 페이지, 전체 PDF와 JSON은 노트의 모든 페이지를 포함하며, 선택 PDF에서는 페이지를 고를 수 있습니다. PDF는 이미지로 저장되며 원본 글자를 직접 편집하는 형식은 아닙니다.

손글씨를 읽어올까요?

현재 페이지에서 변환할 원본 필기 이미지만 Google Gemini 3.1 Flash-Lite로 전송합니다. 인식 사용량에 따라 API 비용이 발생할 수 있습니다. 노트 제목이나 다른 노트는 전송하지 않습니다.

Gemini API 키를 이 칸에 넣지 마세요. 이용 코드는 서버의 AI 기능 보호용이며 브라우저 저장소에 보관하지 않습니다.

처음에는 짧은 문장으로 확인해보세요. 원본은 변경되지 않습니다.
