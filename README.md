# KEPCO 노트 독립 앱 업데이트

첨부 Android 앱 `kepco-note-v100-standalone(6).apk`를 기준으로 하는 업데이트 소스입니다. 웹앱 저장소와 분리하여 관리하며 웹 배포는 수행하지 않습니다.

## 307.7 영상 화면 재생 및 S Pen 떼기/호버 수정

- 영상 화면을 눌러 YouTube 또는 기기 영상을 재생합니다. 선택된 화면의 짧은 탭은 재생, 드래그는 이동이며 크기 조절 핸들은 유지합니다.
- 기기 영상은 불러온 뒤 재생을 시작하고 화면을 눌러 일시정지/다시 재생할 수 있습니다. 재생 막대는 별도로 조작합니다.
- 버튼 지우개는 **펜을 완전히 뗄 때까지** 지우개 상태를 유지합니다. 버튼을 먼저 놓아도 접촉 중에 새 펜 선을 만들지 않습니다. 다음 접촉부터 선택한 펜으로 돌아옵니다.
- 압력 0인 호버/버튼 이벤트와 접촉 없는 이동은 새 필기를 시작하지 않습니다. 네이티브에서도 UP/CANCEL까지 지우개 종류를 유지해 떼기 직전 펜 입력 합성을 막습니다.
- 307.5/307.6과 같은 패키지·서명입니다. 기존 앱을 삭제하지 말고 백업 후 덮어 설치하세요.
- 회귀 테스트 414개, 네이티브 입력 검사 41개, JS 문법 96개 및 APK 서명·정렬 통과. Galaxy Tab S8+ 실기기 동작과 실제 영상 서버 재생은 미검증입니다.

`build_3077.py`는 정확한 307.5 기반 APK와 현재 네이티브 DEX를 입력으로 받습니다. 나머지 빌드/검증 흐름은 307.6과 같습니다.

## 307.6 영상 메뉴 및 S Pen 입력 수정

- 웹앱과 같은 빨간 재생 아이콘의 **영상** 메뉴에서 YouTube 링크와 기기 영상 파일을 선택합니다. X는 지원하지 않습니다.
- YouTube는 노트의 영상 위치에 **별도 WebView**로 표시합니다. 플레이어에는 파일·캘린더 등 노트의 네이티브 브리지가 없으며, 노트 본체의 원격 iframe 차단은 유지합니다. 정확한 앱 origin의 메인 프레임만 제한된 플레이어 메시지를 보낼 수 있습니다.
- 한 번에 하나의 YouTube 영상이 재생됩니다. 선택/이동/크기 조절, 페이지 전환, 대화상자, 화면 밖 이동, 백그라운드 진입 시 재생을 닫습니다. 툴바 아래에 영상 전체가 보일 때 재생하세요. 인터넷 및 최신 Android System WebView가 필요하며 YouTube의 외부 재생 제한 영상은 재생되지 않을 수 있습니다.
- S Pen 옆 버튼 입력을 Chromium의 글자 선택 기능이 가로채기 전에 네이티브 지우개 입력으로 변환합니다. 버튼을 놓으면 펜으로 돌아옵니다. 손가락/마우스 입력과 압력/기울기/이벤트 이력은 유지합니다.
- APK는 307.5와 동일한 **KEPCO S펜** 패키지와 인증서를 사용합니다. 307.5를 삭제하지 말고 덮어 설치하세요. 예전 207 앱과는 별도 앱이며 자동 데이터 이전은 없습니다.
- 실제 Galaxy Tab S8+ 설치·버튼 입력·YouTube 서버 재생은 여기서 검증하지 못했습니다. 자동 테스트와 서명 검사만으로 기기 동작을 보장하지 않습니다.

빌드는 기존 307.5 APK가 필요합니다. 서명키와 APK는 공개 저장소에 넣지 않습니다. `patch_native_input.py`로 네이티브 DEX를 만든 뒤 `build_3076.py`로 소스를 묶고, `verify_3076.py`를 실행한 후 원래 307 서명키로 서명합니다. 네이티브 패치는 기존 클래스 5,686개의 의미를 보존하며 MainActivity의 WebView 생성만 새 하위 클래스로 바꿉니다.

## 307.5 별도 설치 S Pen 앱

S Pen 변경을 포함한 **KEPCO S펜** APK를 새 키로 서명했습니다. 앱 ID는 `kr.kepconote.standalone.v307`이며 기존 207 앱을 덮어쓰지 않는 별도 설치판입니다. 기존 앱과 저장공간이 분리되므로 기존 노트는 자동으로 옮겨지지 않습니다. 기존 앱을 삭제하지 마세요. JSON 백업에는 동영상 원본이 포함되지 않습니다.

APK v2/v3 서명·16 KiB ZIP 정렬·패키지 및 provider/권한 분리·기존 네이티브 DEX 보존을 검사했습니다. 실제 Galaxy 설치·S Pen 입력·Google 캘린더 로그인은 아직 검증하지 않았습니다. Google OAuth는 새 패키지와 서명 등록이 필요할 수 있습니다. APK와 비공개 서명 백업은 저장소에 올리지 않습니다. 공개 빌드 스크립트는 `build_spen_parallel.py`, 검증 정보는 `releases/307.5/release-info.json`입니다.

## Galaxy Tab S8+ S Pen 버튼 지우개 (2026-11-13)

- 필기 중 S Pen 옆 버튼을 누르고 화면에 쓰면 기존 부분 지우개로 동작합니다. 버튼을 놓으면 선택했던 펜 종류·굵기·색상으로 돌아갑니다.
- 화면에 닿은 채 버튼을 눌렀다 놓는 경우에도 획을 분리하여, 지운 구간을 펜 선으로 이어 붙이지 않습니다.
- 공중에서 버튼만 누를 때는 지우지 않으며, 버튼을 누른 채 펜을 대거나 떼는 WebView 포인터 이벤트도 처리합니다. 기존 지우개 선택·실행 취소·손가락 필기·보기 이동 잠금은 유지합니다.
- Android WebView가 표준 펜 버튼 상태를 전달해야 합니다. 삼성 Air command가 입력을 가로채는지와 실제 Galaxy Tab S8+ 동작은 기기에서 확인해야 하며, 실기기 검증은 아직 수행하지 않았습니다.

검증: S Pen 회귀 테스트 6개를 포함한 전체 393개 통과, JavaScript 문법 94개·정적 모듈 연결·APK 자산 보존 검사 통과. 네이티브 DEX는 수정하지 않았습니다.

## 207.5 소스 개선 (2026-11-13)

이번 변경은 **GitHub 소스 업데이트**입니다. 서명된 207.5 APK는 배포하지 않았습니다. 기존 207 서명키 없이는 기존 앱에 호환되는 업데이트 APK를 만들 수 없으며, 미서명 파일을 설치용으로 제공하지 않습니다.

- 백업·복원 화면에서 동영상 원본 제외와 별도 보관·재연결 필요를 명시합니다.
- 복사로 수정 시간이 달라진 영상이나 다른 영상을 사용자 확인 후 연결할 수 있습니다. 위치·크기는 유지하고 이전 저장본은 실행 취소를 위해 남깁니다.
- 백업 저장 요청을 기다리고 오류·취소를 표시합니다. Android 저장 화면을 연 뒤 사용자가 최종 저장했는지는 네이티브 브리지에서 확인할 수 없으므로 저장 완료를 단정하지 않습니다.
- 사이드 메뉴의 **영상 저장공간**에서 용량과 참조 없는 원본을 확인합니다. 노트·휴지통·실행 취소/다시 실행 참조는 보호하며, 잠긴 자료·불확실한 상태·미완료 저장이 있으면 삭제를 막습니다. 자동 삭제하지 않으며 원본별 확인이 필요합니다. 외부 JSON 백업과 다른 창은 조회할 수 없으므로 다른 창을 닫고 원본을 따로 보관한 뒤 정리하세요.
- 영상 출력은 모든 원본의 저장 메타데이터를 먼저 검사해 128 MiB 한도를 넘는 선택을 복호화 전에 차단합니다. 읽기 직전 재검사와 실제 크기 일치 검사도 수행합니다. 기기 메모리·인코더에 따른 실제 재생/출력 성공을 보장하지는 않습니다.

검증: 영상 테스트 109개 + 기존 회귀 테스트 278개 통과, JavaScript 문법 94개와 정적 모듈 연결 검사 통과. 이전 207.4에서도 실패하던 테스트 두 개는 영상 빈 배열 정규화와 영상 렌더러 테스트 더블에 맞게 갱신했습니다. 네이티브 DEX·캘린더·다이어리·상태 표시줄/화면 여백·보안 어댑터는 수정하지 않았습니다. X 기능과 펜 몸체 두 번 두드리기도 추가하지 않았습니다. 실제 Galaxy 설치·재생·출력 검증은 수행하지 못했습니다.


### 재생성

원본 APK에서 107 수정본을 만든 뒤, 별도 설치용 패키지로 변환합니다. Node.js/Python 검증 절차는 아래와 같습니다.

```sh
python build_update.py 'kepco-note-v100-standalone(6).apk'
python build_parallel_apk.py KEPCO-note-107-UNSIGNED.apk KEPCO-note-207-UNALIGNED.apk
zipalign -P 16 -f 4 KEPCO-note-207-UNALIGNED.apk KEPCO-note-207-ALIGNED.apk
apksigner sign --ks /private/path/kepco-note-v207.jks --ks-key-alias kepco-note-v207 --out KEPCO-note-207.apk KEPCO-note-207-ALIGNED.apk
apksigner verify --verbose --print-certs KEPCO-note-207.apk
```
