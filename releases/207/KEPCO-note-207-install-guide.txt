KEPCO 노트 독립판 207.1 설치 안내

KEPCO-note-207.apk는 새 키로 서명한 별도 설치용 APK입니다.
앱 이름: KEPCO 노트 독립판
패키지: kr.kepconote.standalone.v207
Android 8.0 이상 대상이며 기존 v100·v122 앱과 패키지가 다릅니다.
기존 앱을 삭제하지 않고 별도로 설치합니다. 기존 앱의 노트와 로그인 상태가 자동으로 옮겨지지는 않습니다.

설치와 자료 이동
1. Android 기기에서 APK를 내려받아 설치합니다. 사용한 브라우저 또는 파일 앱의 외부 앱 설치 허용이 필요할 수 있습니다.
2. 기존 앱은 그대로 보관합니다.
3. 기존 앱의 백업·복원 관리에서 노트와 다이어리를 각각 파일로 백업합니다.
4. 새 앱의 백업·복원 관리에서 파일을 선택하고 내용을 확인한 뒤 복원합니다.
5. 새 앱에서 노트·사진·필기를 확인하기 전에는 기존 앱이나 백업을 지우지 마세요. 녹음 원본 등 노트 백업에 포함되지 않는 자료는 별도로 보관해야 합니다.

Google 캘린더
캘린더 코드는 기존 수정 기준 APK와 동일합니다. 다만 새 패키지와 인증서이므로 기존 Google 인증 등록을 그대로 사용할 수 없습니다.
Google Cloud의 기존 캘린더 인증 프로젝트 → Google Auth Platform → Clients → Create client → Android에서 다음 값을 추가해야 합니다.
기존 Android OAuth 클라이언트를 삭제·변경하지 말고 새 클라이언트를 추가합니다.
패키지 이름: kr.kepconote.standalone.v207
SHA-1: FD:AD:80:32:19:B9:A9:D6:B6:76:F9:5A:17:F9:CB:5E:5E:45:FA:03
같은 프로젝트에서 Calendar API 및 필요한 동의/테스트 사용자 설정을 확인한 다음 새 앱에서 연결을 시험합니다.
현재 이 Google Cloud 등록 작업과 실기기 로그인 검증은 완료되지 않았습니다. 구글 연결이 필요하면 등록 후 이용하세요.
공식 안내: https://developer.android.com/identity/authorization
